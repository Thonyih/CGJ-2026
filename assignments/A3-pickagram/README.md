# Assignment A3 - 3D Pickagram

The A2 shark in 3D: 7 Tangram pieces made in Blender, loaded with Assimp, standing on a table. They can be animated into their box (a closed square lying on the table) and back. Built on the lecture code `hello-3d-world` (camera, UBO) and `mesh-loader` (`mgl::Mesh`, Assimp). The teacher's `mgl` is used **unchanged**.

## Run (Visual Studio Community 2022 or 2026)

1. Open **`A3-pickagram.sln`**.
2. Press **F5**.

Everything is in the folder:
- The libraries are compiled with the program, so there's nothing to install.
- The first build takes about a minute, because of Assimp.
- Delete `build\` and `.vs\` before zipping.

## Controls

| Input | Action |
|---|---|
| **Left / Right arrow** (hold) | Animate the pieces into the box / back into the shark. Let go to stop halfway; press either key to continue or reverse |
| **Left mouse** drag | Move the table and everything on it. Left/right moves along the camera's right vector; up/down moves along its front vector (away from / towards the camera) |
| **Right mouse** drag | Orbit the camera around its centre |
| **Scroll wheel** | Move the camera closer / further |
| **C** | Switch between the 2 cameras. Each keeps its own position |
| **P** | Switch the current camera between perspective and orthographic |

Camera 0 starts looking at the shark, and camera 1 starts looking down at the box.

## How each requirement is met

| Requirement | Where |
|---|---|
| 3D shapes made in Blender, exported, loaded with Assimp | `assets/blender/make-pieces.py` builds the meshes in Blender and exports `assets/models/*.obj`. `mgl::Mesh` (lecture code) loads them with Assimp |
| Organisation of the shape classes; model-space position | 3 meshes (`triangle`, `square`, `parallelogram`) shared by the 7 pieces, as in A2. Each is the A2 shape with **corner 0 at the origin**, made `0.1` thick along z. The table's top surface is at y = 0 |
| A distinct colour per piece, a different tint per face | `Color` uniform per scene node. `pickagram-fs.glsl` scales it by `0.75 + 0.2 · dot(normal, fixed direction)`, so each face gets its own tint (55–95 %) without lighting |
| Scene graph: mesh + shader + model matrix, hierarchical | `SceneNode` (section 2). `draw()` uses `world = parentWorld * ModelMatrix`. Tree: Root → Table → {TableTop, Pickagram → 7 pieces} |
| The Pickagram on a table that moves with it | The pieces are children of `Table`. A left-mouse drag changes only `Table.ModelMatrix` |
| Box configuration on a different plane | Box: lying flat in the x-z plane (the 2D Tangram square turned −90° around x). Shark: standing in the x-y plane |
| Arrow-key animation that can stop and reverse | `animate()`: `Progress` goes 0 (box) … 1 (shark) only while a key is held. Position uses `glm::mix`, rotation uses `glm::slerp` of quaternions |
| 2 orbiting cameras, right-mouse orbit, scroll zoom | `OrbitCamera` (section 3): centre, distance, quaternion orientation. View matrix = `glm::lookAt` |
| Quaternions, no gimbal lock | The camera turns around its **own** up and right axes (`Orientation * turn`), never with fixed Euler angles |
| C switches cameras and keeps their state; P switches projection | `keyCallback`. `Cameras[2]`, each with its own `Perspective` flag |
| Default cameras show both configurations | Camera 0 centred on the shark, camera 1 on the box |
| No stretching on resize | `windowSizeCallback` stores the size, and the projection uses `aspect = width / height` |

## Files

| File | Contents |
|---|---|
| `src/A3-assignment.cpp` | The whole program |
| `src/pickagram-vs.glsl` | Vertex shader (lecture camera block + `ModelMatrix`) |
| `src/pickagram-fs.glsl` | Fragment shader: piece colour × face tint |
| `assets/blender/make-pieces.py` | Blender script that makes and exports the meshes (`blender --background --python make-pieces.py`) |
| `assets/blender/pickagram.blend` | The Blender file it saves |
| `assets/models/*.obj` | The exported meshes |
| `mgl/` | The teacher's framework (from `04-mesh-loader`), unchanged |
| `libraries/` | GLM, GLFW, GLEW, and Assimp 5.4.3 (only the OBJ importer; `config.h` and `revision.h` were written by hand instead of being generated by CMake) |
| `A3-pickagram.sln`, `.vcxproj`, `.vcxproj.filters` | Visual Studio solution and project |
